# Victoria 2 v3.04: correcciones

El repositorio tiene dos carpetas principales:

| Carpeta | Qué contiene |
|---|---|
| [`juego-base/`](juego-base/) | Correcciones del juego base, herramientas para jugadores e informe |
| [`upm/`](upm/) | Correcciones de Universal Project Mod 2.05, que se aplican sobre el juego base ya corregido, e informe |

Aquí no hay archivos del juego ni del mod: son propiedad de sus autores. Solo hay scripts y documentación, que se aplican sobre tu propia copia.

## Orden de uso

1. Corrige el juego base con `juego-base/base_fix.py`.
2. Haz una copia de la carpeta del juego, instala en ella UPM sin tocar y aplica `upm/upm_fix.py`.

El detalle de cada paso está en el informe de cada carpeta.

## Probar sin instalar Python

Hay dos parches descargables que se aplican con doble clic: la [versión de prueba del juego base](https://github.com/KH4IN/Victoria-2-dlcs-fix/releases/tag/base-prueba-1) y la [versión de prueba de UPM](https://github.com/KH4IN/Victoria-2-dlcs-fix/releases/tag/upm-prueba-1). Los errores se comunican en [Issues](https://github.com/KH4IN/Victoria-2-dlcs-fix/issues).
